# Prompt Review Checklist

每次新增或升级 Prompt 版本时，逐项检查并在 bad case 记录中说明结果。

## 职责

- [ ] Prompt 只承担一个 Agent 职责。
- [ ] 已明确允许执行的任务和禁止执行的任务。
- [ ] 用户输入被当作不可信数据，不会覆盖系统规则。

## 输入契约

- [ ] 每个模板变量都有名称、含义和格式说明。
- [ ] 缺少变量或传入未知变量时会立即失败。
- [ ] 用户原始文本经过明确分隔或序列化后再注入。

## 输出契约

- [ ] 输出格式能够被 Zod Schema 或其他确定性代码校验。
- [ ] 字段范围、枚举值和默认值清晰且与 Schema 一致。
- [ ] 禁止 Markdown、解释文本和多余外层结构等格式漂移。

## 安全与可观测性

- [ ] Prompt 不要求模型输出链式思考或隐藏推理。
- [ ] 日志和 Timeline 只记录版本、阶段、耗时、错误与可展示摘要。
- [ ] Prompt 内容、用户隐私和密钥不会进入不必要的日志。

## 版本与回归

- [ ] 修改使用新版本号，旧 bad case 仍可复现。
- [ ] 固定评测集全部重新执行，并记录修改前后差异。
- [ ] `pnpm test`、`pnpm lint`、`pnpm build` 全部通过。
