# 课程页面设计

## 目标

把当前页面一次做成可学习、可操作、可交付的作品。先完成 PageTask 的唯一教学职责，再选择内容、互动、素材和构图；不要从模板、卡片数量或评分项反推页面。

## 工作方法

1. 读取 PageTask、整课目标、相邻页面职责和已验收依赖摘要，明确本页只推进哪一个主要认知动作。
2. 选择能让学习者完成该动作的最小充分事实、关系、例子或反例；不复制相邻页面填充版面。
3. 让互动承担回忆、比较、判断、应用或探索中的一种真实学习任务；不需要互动时保持 `none`。
4. 选择一个主视觉焦点和一条清晰阅读路径。布局可以变化，但标题、关键解释和主要操作必须在播放器画布内形成完整任务。
5. 素材只有在能解释关系、建立情境或降低理解成本时才使用；不要让装饰替代教学内容。
6. 首次生成就完成内容与表现的整体设计。QA 用于发现具体缺口，Repair 只处理有证据、可定位的问题。

## 渐进读取

- 需要选择页面构图、处理低高度画布、图文关系或信息密度时，读取 `references/fixed-canvas-composition.md`。
- 页面包含 choice、reveal、sort、input 或 explore，或者需要判断是否真的应有互动时，读取 `references/learning-interactions.md`。

## 交付判断

- 学习者能在本页完成 PageTask 的 learnerAction，并产生 acceptance 所要求的证据。
- 内容、互动和视觉表达围绕同一个主任务，不是互不相干的模块拼盘。
- 页面与前后页分工明确，术语和事实保持连续。
- 固定画布约束通过分组、层级和构图自然满足，不靠缩小正文、裁切必要内容或制造嵌套滚动。
- 技术合同、安全标记和稳定 ID 由既有工具与 Schema 保证，不在创作方法中重复堆砌。

## 避免

- 不把所有内容做成等权卡片。
- 不用超大标题、装饰插图或重复任务说明挤压核心内容。
- 不为了“看起来有互动”添加无法证明学习结果的控件。
- 不先生成空泛初稿，再依赖 QA 分数指导创作。
