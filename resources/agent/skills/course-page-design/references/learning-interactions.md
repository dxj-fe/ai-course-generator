# 学习互动设计

## 选择互动

互动类型由学习证据决定：

- `none`：本页只需建立理解，额外操作不会增加证据。
- `navigate`：学习动作是选择学习路径，不把普通“下一页”包装成考核。
- `reveal`：学习者应先预测或观察，再按需揭示解释。
- `choice`：需要根据明确依据作出判断；干扰项对应真实误解。
- `sort`：目标是识别顺序、层级或流程关系。
- `input`：需要学习者组织解释、方案或反思；评价标准必须可观察。
- `explore`：不同选择会暴露有意义的关系，而不是仅切换装饰内容。

如果互动不能更好地证明 learnerAction，就不使用它。

## 形成完整学习回路

一次有效互动包含：

1. 学习者知道要完成什么。
2. 页面在操作前提供作出判断所需的依据。
3. 操作结果对应目标中的判断、比较、应用或解释。
4. 成功反馈解释为什么成立。
5. 重试反馈指出缺失的判断依据，并给出下一步线索。

反馈不要只写“正确”“很棒”或“再试一次”。选择题通常只保留一题，集中检验最关键的判断依据；开放输入只列真正可观察的评价标准。

## 与内容协同

- 不在静态内容块和互动区完整重复同一题目、选项或任务说明。
- 互动是页面主任务时，让操作区成为视觉焦点，内容块只提供必要依据。
- 互动是辅助理解时，保持轻量，不挤压核心解释。
- 图片、动画感构图和控件不能替代明确的题意、反馈和无障碍文本。
