# 学习目标与证据

## 从意图到可观察结果

宽泛意图不能直接作为课程目标：

| 宽泛意图 | 可观察结果 | 合适证据 |
| --- | --- | --- |
| 了解光合作用 | 能用自己的话解释输入、过程和产物 | 补全流程并解释每一步 |
| 学会时间管理 | 能为一周任务制定有优先级的计划 | 对真实任务排序并说明取舍 |
| 理解概率 | 能比较两个事件的可能性并说明依据 | 预测、计算或解释反例 |

优先使用“解释、区分、比较、判断、应用、构建、诊断、反思”等能产生证据的动词。避免只写“了解、熟悉、掌握”。

## 目标—页面—证据矩阵

提交前检查：

1. 每个目标至少有一页负责建立理解。
2. 每个目标至少有一处要求学习者输出、选择、操作或解释。
3. 证据确实能区分“看过内容”和“已经学会”。
4. 一个页面可以服务多个紧密相关目标，但不能只靠标签声称覆盖。
5. 页数受限时，优先合并重复讲解，不删除关键学习证据。

## 难度推进

通常从识别和解释推进到比较、应用和迁移。不要机械套用固定层级；根据受众先验知识决定起点，并让每一步只增加一个主要认知负担。
