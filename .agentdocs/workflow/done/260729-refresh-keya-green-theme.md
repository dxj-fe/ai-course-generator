# 课芽全产品绿色主题改造（已完成）

## 目标

在不改变数据来源、路由、课程生成、筛选搜索、播放器和 Prompt 提交逻辑的前提下，
把课芽全部产品壳层改造成以绿色为核心、清新且带卡通感的统一品牌界面，并强化响应式体验与动效。

## 视觉与交互方案

- 视觉论点：春日芽田里的课程创作入口，以嫩芽绿、奶油白和少量芒果黄构成层次。
- 页面范围：`/`、`/chat`、`/course`、`/course/[courseId]`、`/templates`、
  `/preview/[previewId]`、`/analysis/course-generation` 及其共享产品组件。
- 品牌锚点：使用无文字的课芽学习伙伴插画；聊天、课程库、播放器、模板和分析页面共享
  芽叶、纸张、薄荷画布和柔和绿色阴影语言。
- 动效：首页保留分层入场和插画轻浮；子页面使用更克制的页面入场、状态呼吸、
  面板/按钮/导航悬停反馈，避免妨碍操作。
- 可访问性：所有持续动效在 `prefers-reduced-motion` 下停用；交互元素保留语义、焦点和键盘行为。
- 响应式：移动端标题自然换行、精选课程横向滚动；聊天双栏、播放器侧栏、
  模板和分析画布继续沿用现有响应式交互，不能因装饰产生裁切。

## 实施边界

- 不修改任何服务、课程完成条件、Prompt 参数、状态所有权和目标路由。
- 不修改课程 iframe 内的生成 HTML、模板预览内容或其沙箱权限；统一的是平台壳层。
- 共享品牌色通过现有 `--keya-*` token 统一，页面装饰与持续动效使用 `keya-home-*`
  或其他明确作用域，避免把高强度首页动效扩散到工作界面。
- 继续复用 `CourseCoverFrame`、本地 shadcn/ui 控件和 `lucide-react` 图标。

## 验收标准

- 全部用户可见产品路由均使用一致的绿色、薄荷画布、暖白纸张、芽叶装饰和圆润反馈语言。
- 桌面端和 390px 移动端无新增横向裁切，主要操作与原响应式流程可用。
- Prompt、附件、课程任务、课程跳转、搜索筛选、模板预览、播放器控制和分析画布行为不变。
- 首页具有明确的卡通视觉锚点和至少三类可感知动效；操作型子页面动效克制并支持减少动态效果。
- ESLint、TypeScript/Next build 和相关 Vitest 测试通过。
